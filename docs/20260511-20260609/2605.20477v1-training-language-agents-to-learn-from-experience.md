## 摘要
语言智能体能够在交互式环境中从经验中适应，但当前基于反思的方法只能在单个任务实例内进行自我纠正。这种经验能否提炼为可复用的经验教训，以提升未来未见任务的表现，仍不清楚。我们通过引入上下文训练（ICT）任务来解决这一问题，这是一个评估语言智能体跨任务自我改进的框架。在ICT中，反思模型观察由行动模型收集的轨迹，并生成旨在提升行动模型在未来未见任务上表现的系统提示。然后，我们提出了一种基于强化学习的训练流程，直接从经验中学习此类反思，无需人工提供示例。在ALFWorld和MiniHack中，我们训练的反思器在大多数留出的任务家族上优于未训练的基线，表明从经验中学习的能力本身是可以学习的。在某些情况下，我们观察到超越反思器训练基准的泛化能力，泛化到截然不同的环境。最后，我们引入了MetaGym，一个用于构建元环境的通用Python库，以赋能未来关于自我改进语言智能体的研究。

## Abstract
Language agents can adapt from experience in interactive environments, but current reflection-based methods can only self-correct within a single task instance. Whether such experience can be distilled into reusable lessons that improve performance on future unseen tasks remains unclear. We address this problem by introducing the In-context Training (ICT) task, a framework for evaluating cross-task self-improvement in language agents. In ICT, a reflector model observes trajectories collected by an actor model and generates system prompts intended to improve the actor's performance on future unseen tasks. We then propose an RL-based training pipeline for learning such reflections directly from experience, without human-provided examples. Across ALFWorld and MiniHack, our trained reflectors outperform an untrained baseline on most held-out task families, showing that the ability to learn from experience can itself be learned. In some cases, we observe generalisation beyond the benchmark on which the reflector was trained, to substantially different environments. Finally, we introduce MetaGym, a generic Python library for constructing meta-environments, enabling future research on self-improving language agents.

*   **核心问题**: 语言智能体能否将从交互经验中获得的洞察提炼为**可跨任务复用的知识**，从而提升在未来全新任务上的表现，而非仅仅在同一任务上进行自我纠正。
*   **研究动机与背景**:
    *   当前基于反思的语言智能体方法（如 Reflexion）只能在**单个任务实例**内循环尝试、自我纠正，一旦任务完成，学到的经验无法迁移到新任务。
    *   在许多现实场景中，重复执行完全相同的任务是不可能的（如下棋、烹饪），因此智能体必须具备从非重复的、连续的在线经验中跨任务学习的能力。

### 2. 论文提出的方法论

*   **核心思想**: 采用双模型设计（行动者与反思器），通过优化**系统提示**来实现语言智能体的跨任务自我进化。反思器通过观察行动者的行为轨迹，生成能提升未来任务表现的通用系统提示，并且该反思能力本身通过强化学习进行训练。

*   **关键技术细节**:
    *   **In-context Training (ICT) 任务 (评估框架)**:
        *   **双模型设计**: `行动者`负责在环境中执行任务，其策略由其自身的参数和收到的`系统提示`决定；`反思器`负责分析行动者的交互轨迹，并生成新的系统提示来改进行动者。
        *   **元循环**: 每个“元回合”，反思器基于上一轮的系统提示和行动者在一批新任务上的交互轨迹，生成一个改进后的系统提示。行动者随后用新提示去执行下一批新任务。
        *   **不可重复性**: 行动者在每个元回合面对的都是全新的、未见过的任务，模拟了现实中的在线学习场景，迫使反思器学习可泛化的规则。
    *   **基于强化学习的反思器训练流程**:
        *   **目标**: 训练LLM成为能进行跨任务自我改进的反思器，不依赖人工标注数据。
        *   **数据集构建**: 使用一个基础模型运行多次完整的ICT循环，记录下每个元回合的 `(当前系统提示，行动者生成的轨迹，执行的任务批次)` 三元组，构成训练数据集D。
        *   **奖励信号**: 训练时的奖励并非来自未来任务，而是来自**重放上一批次任务**。具体而言，对于反思器生成的新提示 `sp_i`，其奖励是行动者使用 `sp_i` **重新执行上一批任务**所获得的平均奖励。这一设计旨在鼓励反思器分析并解决在已观察到的轨迹中暴露出的问题。
        *   **训练算法**: 使用组相对策略优化(GRPO)算法进行微调。在每个训练步，反思器基于数据集中的一个批次和对应的轨迹生成一组候选提示，然后通过重放任务批次的真实表现来计算每个候选提示的奖励，并用GRPO更新反思器参数。

### 3. 实验设计

*   **数据集/场景**:
    *   **ALFWorld**: 一个家庭环境的文本交互基准，包含6种任务类型。
    *   **MiniHack**: 一个基于网格世界的2D游戏环境基准，实验选取了8种5x5网格环境的任务类型。
*   **基准任务划分 (Task Partitioning)**:
    *   为避免反思器仅仅记忆特定任务类型的优秀提示，评估采用**按任务类型划分**的方式，而非按任务实例划分。
    *   **ALFWorld**: 使用 `Pick and Place`, `Examine in Light`, `Clean and Place`, `Heat and Place` 四种类型作为元训练集；使用 `Cool and Place` 和 `Pick Two and Place` 两种类型作为元测试集。
    *   **MiniHack**: 使用 `Room-Random-5x5`, `Eat`, `Wield`, `Wear` 四种类型作为元训练集；使用 `PutOn`, `Zap`, `Read`, `Room-Dark-5x5` 四种类型作为元测试集。
*   **对比方法/基线**:
    *   **初始提示**: 使用未经任何优化的初始系统提示所取得的平均成功率。
    *   **未训练的基础模型**: 使用未经微调的 Qwen2.5-7B-Instruct 模型在ICT框架下运行的性能。
    *   **论文提出的方法**: 训练后的反思器（Trained）。

### 6. 论文的主要结论与发现

*   **“学习能力”是可学习的**: 经过训练的反思器在绝大多数未见过的全新任务类型上，其表现均优于未训练的基线模型，证明了从经验中学习以进行跨任务自我改进的元技能，是可以通过强化学习训练获得的。
*   **持续改进能力**: 即使在训练数据仅包含4个元回合的情况下，训练后的反思器在测试时能够持续进行超过4轮的自我改进，表现出对生成提示的**递归优化能力**，能够“举一反三”。
*   **跨基准泛化性**: 在MiniHack上训练的反思器（特别是批次大小为5的模型）能够将其学习能力迁移到结构迥异的ALFWorld环境中，并在多个任务上取得超越基线的表现，显示出元技能的通用性。
*   **批次大小的影响**: 较大的交互批次（k=5）在困难任务（如MiniHack-Zap）上训练效果更好，因为它能提供更多样化的经验和更密集的奖励信号；而较小的批次（k=3）在计算效率和冗余信息方面可能更有优势。

### 7. 优点

*   **新颖的范式**: 将研究焦点从“单任务内反思”转向“跨任务经验学习”，提出了ICT任务这一新的评估框架，对构建通用智能体具有重要意义。
*   **无需人工标注的训练方法**: 提出的RL训练流程完全从环境交互中自动生成训练数据和奖励信号，不需要任何人类编写的示例或反思样本，自动化程度高。
*   **严谨的实验评估**: 采用按任务类型划分训练和测试集的方法，有效地测试了模型的元泛化能力，实验设计具有说服力。
*   **开源贡献**: 发布了MetaGym库，为后续研究LLM智能体在元学习环境下的自我改进提供了标准化的工具和平台，有助于社区发展。

### 8. 不足与局限

*   **双模型架构的成本**: 训练和部署时需同时维护行动者和反思器两个大模型，显存占用和计算成本较高。文中也提到了单模型承担双重角色的未来方向。
*   **评估依赖固定验证集**: ICT循环中挑选最佳提示的步骤依赖于一个固定的、可重复使用的留出验证集，这在某些现实应用中可能不存在。论文提到了终身学习作为替代方案，但未深入探索。
*   **RL算法单一**: 训练反思器仅采用了GRPO算法，未与其他PPO等主流算法进行比较，缺乏算法选择上的消融实验。
*   **任务与环境的局限性**: 实验仅在ALFWorld和简化版的MiniHack上进行，这些环境的任务结构和复杂性相对有限，方法在更复杂、更开放的真实世界场景中的有效性有待验证。
*   **模型与训练稳定性**: 论文未深入探讨长序列训练下的稳定性问题，以及模型在长期自我优化后生成提示的质量是否会退化。
