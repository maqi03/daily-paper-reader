## 摘要
自动提示优化在基于LLM的智能体工作流程中取得了显著进展。然而，现有方法将每个任务的提示视为一个单一的、无视实例的字符串，通过全局编辑进行优化，导致更新脆弱且无法重用已学习的子行为。我们提出了提示码本（PCO），这是一种新颖的组合式提示优化框架，将自动提示优化重新定义为在有限自然语言本能——原子化的、可复用的指令单元——词汇表上的离散学习。PCO将提示构建知识组织在一个离散码本中，并通过基于LLM的编码器将每个输入路由到码本的一个小子集；生成器将它们组合成适用于冻结目标模型的提示；评判器发出结构化裁决，通过归因分解为每个变量的文本梯度，在语言值极小极大目标下联合训练编码器、生成器和码本。最终的路由结果是针对每个实例的：同一任务中的不同输入会得到不同的本能组合，这种机制在无视实例的方法中无法表达。在Qwen3-8B和LLaMA-3.1-8B上的六个基准测试中，PCO相比零样本最多提高了+30.36分，在HotpotQA上比最强基线（GEPA）高出+3.34分，总体高出+1.11分，并且仅使用K=16个本能，部署提示长度相比MIPROv2最多减少14.1倍，相比GEPA减少3.0倍。

## Abstract
Automatic prompt optimization (APO) has driven significant gains in LLM-based agentic workflows. However, existing methods treat each task's prompt as a monolithic, instance-blind string optimized through global edits, producing brittle updates and preventing the reuse of learned sub-behaviors. We propose Prompt Codebooks (PCO), a novel compositional prompt optimization framework that recasts APO as discrete learning over a finite vocabulary of natural-language instincts - atomic, reusable instruction units. PCO organizes prompt-construction knowledge in a discrete codebook and routes each input to a small subset of entries via an LLM-based encoder; a generator composes them into a prompt for the frozen target model; a critic emits a structured verdict that decomposes by attribution into per-variable textual gradients, jointly training the encoder, generator, and codebook under a language-valued min-max objective. The resulting routing is per-instance: different inputs in the same task receive different instinct compositions, a regime structurally inexpressible under instance-blind methods. Across six benchmarks on Qwen3-8B and LLaMA-3.1-8B, PCO improves over zero-shot by up to +30.36 points, surpasses the strongest prior baseline (GEPA) by +3.34 on HotpotQA and +1.11 in aggregate, and reduces deployed prompt length by up to 14.1x versus MIPROv2 and 3.0x versus GEPA using only K=16 instincts.

### 1. 核心问题与研究动机

- **现有方法的痛点**：目前主流的自动提示优化（APO）方法将每个任务的提示视为一个整体的、无视实例（instance-blind）的文本字符串，通过全局编辑进行优化。这种做法会导致：
    - **更新脆弱**：一次失败的修正可能重写整个提示，破坏其他原本有效的部分（全局纠缠）。
    - **无法复用**：学习到的子行为（如“先分解问题再回答”）无法被结构化地保存和在不同输入间重用。
    - **缺少自适应能力**：同一个提示被固定地应用于所有输入，无法针对难易不同的样例进行差异化调整。
- **研究动机**：受离散码本模型（如 VQ-VAE）在图像合成、音频编码中的成功启发，本文试图将提示优化重新定义为一种**离散组合学习**问题，通过构建一个共享、可学习的“自然语言本能”码本，实现提示的结构化复用、实例级自适应和局部信用分配，从而突破传统方法的局限。

### 2. 方法论：提示码本优化（PCO）

PCO 用一个由三个可训练组件和一个离散码本构成的管道，替代了传统的单一提示字符串。

- **核心组件**：
    - **离散码本（$C$）**：一个具有 $K$ 个条目的集合，每个条目 $c_k$ 都是一条简短的自然语言指令（即“本能”），如“分解为子问题再回答”。码本本身是可优化的变量。
    - **提示编码器（$E_\theta$）**：一个带有系统提示 $\theta$ 的 LLM，负责将输入 $x$ 语义路由到码本中的 $S$ 个离散索引（$S \ll K$），实现**实例级自适应**路由。
    - **提示生成器（$G_\phi$）**：一个带有系统提示 $\phi$ 的 LLM，将选中的 $S$ 条本能组合成最终的流畅提示 $p$。
    - **评判器（$D_\psi$）**：一个带有固定角色提示的 LLM，作为**冻结的对抗者**，输出结构化的自然语言反馈（文本梯度），识别失败行为并归因到具体组件。

- **训练目标与流程**：
    - **目标函数**：采用一个语言值的“极小-极大”目标（公式6）：$\Theta^\star = \arg\max_{\theta,\phi,C} \min_{\psi} \mathbb{E}[r - \rho(D_\psi(\dots))]$。即最大化任务奖励 $r$ 减去评判器输出的惩罚项 $\rho$。
    - **信用分配**：评判器的反馈文本 $\ell_{\text{text}}$ 通过 LLM 实现的归因算子（$\text{Attr}$）分解为三个独立的文本梯度：
        - $g_\phi$：评估生成器是否精确渲染了选中的本能（生成器保真度）。
        - $g_{c_k}$：评估每条活跃本能的质量（码本更新）。
        - $g_\theta$：评估编码器路由的准确性（路由一致性）。
    - **优化算法（算法1）**：
        1. 前向传播：编码器路由 $\to$ 生成器组合 $\to$ 冻结的目标 LLM 执行。
        2. 评判器对输出生成文本裁判 $\ell_{\text{text}}$。
        3. 归因并分解为 $g_\phi, g_\theta, g_{c_k}$。
        4. 通过 LLM 调用分别更新 $\phi, \theta, C$（无封闭形式的梯度计算）。
    - **关键设计**：
        - **$\epsilon$-贪婪路由**：训练时以概率 $\epsilon$ 随机探索，防止码本条目“死亡”，$\epsilon$ 从 $1.0$ 衰减至 $0.15$。
        - **成功加权采样**：探索时偏向于历史上成功率高的本能，提升探索效率。

### 6. 主要结论与发现

- **性能全面提升**：PCO 在所有任务上均超越零样本基线，并在多数任务上超越最强进化方法 GEPA。在 Qwen3-8B 上，总体均值提高 **+10.73 分**，超出 GEPA 的 **+9.62 分**；在 HotpotQA 上特异性高出 GEPA **+3.34 分**。

### 7. 优点

- **范式创新**：首次将离散码本的思想引入提示优化，赋予提示组合性、可复用性和实例自适应能力，框架新颖、动机合理。
- **架构优雅**：整个系统“语言原生”，所有优化变量都是文本，梯度也是文本，无需连续嵌入，完全基于 LLM 调用实现。
- **局部信用分配**：通过归因算子将反馈精准定位到具体的本能、生成器或路由器，实现了精细化的更新，避免了全局编辑的干扰。
- **实验扎实**：在多个推理范式、多种基座模型上与最强基线对比，消融实验详尽，且公开了方差和模板，可复现性强。

### 8. 不足与局限

- **计算开销较高**：训练过程涉及多次 LLM 调用（评判、归因、更新），计算成本高于启发式搜索方法（如 GEPA），虽然论文给出了调用次数，但未与基线训练总耗时进行直接对比。
- **格式化任务精度潜在受损**：论文意识到，激进的压缩可能牺牲格式敏感任务（如 IFBench）上的语法精度，GEPA+Merge 在某些任务上（HoVer）仍更具优势。
- **固定离散瓶颈**：码本大小 $K$ 和选择个数 $S$ 需要预设且固定，编码器的语义路由能力受限于此，对更大规模潜在空间的扩展性尚不明确。
- **缺乏跨任务迁移实验**：论文提到了“跨任务迁移”作为未来工作，但当前方法是在每个任务上独立训练专用码本，没有验证通用码本在多任务场景下的表现。
- **基座模型规模限制**：实验仅在 8B 参数的开源模型上进行，未验证在更大模型（如 70B）或闭源模型上的效果。
