## 摘要
大语言模型（LLMs）对用于指定任务目标和行为约束的提示高度敏感。最近许多提示优化方法迭代地使用LLM生成的反馈重写提示，但得到的提示通常变长，积累狭窄的样本特定规则，且在训练分布之外的泛化能力较差。我们将这种失效模式视为提示分布过拟合，并认为它反映了离散文本空间优化中表征控制的缺乏。我们通过表征低效性来形式化这一观点，这是一种双因素度量，将提示低效性分解为容量成本和范围狭窄性，将分布上的提示过拟合归因于优化过程中这两者的耦合增长。我们提出了TextReg，一个正则化框架，通过正则化的文本梯度实现软惩罚目标，结合了双证据梯度净化、语义编辑正则化和正则化引导的提示更新。在多个推理基准上，TextReg显著提升了分布外（OOD）泛化能力，与TextGrad相比准确率提升最高达+11.8%，与REVOLVE相比提升+16.5%。

## Abstract
Large language models (LLMs) are highly sensitive to the prompts used to specify task objectives and behavioral constraints. Many recent prompt optimization methods iteratively rewrite prompts using LLM-generated feedback, but the resulting prompts often become longer, accumulate narrow sample-specific rules, and generalize poorly beyond the training distribution. We study this failure mode as prompt distributional overfitting and argue that it reflects a lack of representation control in discrete text-space optimization. We formalize this view through representational inefficiency, a dual-factor measure that decomposes prompt inefficiency into capacity cost and scope narrowness, attributing distributional prompt overfitting to their coupled growth during optimization. We propose TextReg, a regularization framework that realizes a soft-penalty objective through regularized textual gradients, combining Dual-Evidence Gradient Purification, Semantic Edit Regularization, and Regularization-Guided Prompt Update. Across multiple reasoning benchmarks, TextReg substantially improves out-of-distribution (OOD) generalization, with accuracy gains of up to +11.8% over TextGrad and +16.5% over REVOLVE.

# TextReg：通过正则化的文本空间优化缓解提示分布过拟合

## 1. 论文的核心问题与整体含义

- **研究动机**：当前基于反馈的提示优化方法（如 TextGrad、REVOLVE）虽能在训练数据上提升性能，但迭代优化后的提示往往会 **变长、积累大量样本特异的局部规则**，导致 **在分布外（OOD）输入上的泛化能力严重下降**，甚至不如未优化的零样本提示。
- **核心问题本质**：作者将这种退化现象定义为 **提示分布过拟合**（prompt distributional overfitting），并指出其根源是离散文本空间优化中 **缺乏对提示表征结构的控制**。
- **理论视角**：提出 **表征低效性**（representational inefficiency）的概念，将提示的无效增长分解为两个耦合因子：
  - **容量成本（capacity cost）**：提示长度（token 数）消耗有限的上下文窗口；
  - **范围狭窄性（scope narrowness）**：提示中的规则仅适用于极窄的输入范围（如仅对特定实体或场景有效）。
- **整体含义**：论文旨在通过正则化手段，在文本空间优化中显式控制表征低效性的增长，从而得到 **简短、通用且泛化性强** 的提示。

## 2. 论文提出的方法论

### 2.1 核心思想与目标函数

将提示优化建模为一个正则化目标：

\[
\min_{p \in \mathcal{P}} \mathcal{L}_{\mathcal{D}_{\text{train}}}(p) + \lambda \cdot I(p)
\]

其中 \(I(p) = |p|_{\text{tok}} \times (1 - \bar{s}(p))\)，即容量成本乘以平均规则狭窄度，用于度量提示的表征低效性。正则项惩罚长度增长和狭隘规则累积。

### 2.2 关键技术路线：三阶段正则化文本梯度

由于文本空间不可微，TextReg 将每次提示更新分解为两个互补的自然语言信号：

\[
\mathbf{g}_{\text{text}}(p_t) = \tilde{\mathbf{g}}_{\text{task}}(p_t) + \mathbf{g}_{\text{reg}}(p_t)
\]

并分三阶段实现：

**阶段一：双证据梯度纯化（Dual-Evidence Gradient Purification）**

- 对原始任务反馈梯度进行条件投影，只保留 **泛化性规则**，过滤两种有害梯度：
  - **案例补丁**（CASE_PATCH）：源自少数训练例、无法泛化的局部规则；
  - **纯风格修改**（STYLE_ONLY）：仅改变措辞而无行为价值的改动。
- 证据来源：
  - **局部批次证据**：判断梯度是否高度依赖当前 mini-batch 的具体输入；
  - **全局复发证据（RuleBank）**：维护一个跨步骤的规则库，统计每条泛化规则在优化历史中被清理后保留的次数，用频率近似规则的泛化范围。
- 纯化决策：仅当梯度不被判定为局部补丁或纯风格、且具有足够的 RuleBank 复发支持时，才将其压缩为一句通用的行为原则并向后传递。

**阶段二：语义编辑正则化（Semantic Edit Regularization）**

- 从最近一次提示的编辑（\(p_{t-1} \to p_t\)）中诊断表征低效性的变化：
  - **容量通道**：若提示相对长度增长率超过阈值 \(\tau_C\)（论文取 0.2），触发压缩指令；
  - **范围通道**：用 LLM 实现的语义差分分析器比较新旧提示的规则变化，检测是否新引入了更狭隘的规则，若范围变窄则触发泛化指令。
- 根据触发的通道，生成一个 **正则化文本梯度** \(\mathbf{g}_{\text{reg}}\)，指示应采用压缩、融合或拓宽规则的具体编辑方向。

**阶段三：正则化引导的提示更新（Regularization-Guided Prompt Update）**

- 先用纯化后的任务梯度 \(\tilde{\mathbf{g}}_{\text{task}}\) 约束更新方向，生成“任务忠实候选集”；
- 再从中选出与正则化梯度 \(\mathbf{g}_{\text{reg}}\) 最兼容的候选进行改写，以实现 **任务性能与表征效率的平衡**；
- 若两者冲突，则优先保证任务求解，仅回退到无正则约束的更新。

## 6. 论文的主要结论与发现

- **OOD 泛化显著提升**：TextReg 在绝大多数（测试引擎，数据集）组合中取得最佳或次优结果，较 TextGrad 最高提升 **+11.8%**，较 REVOLVE 最高提升 **+16.5%**。
- **控制过拟合效果明显**：TextGrad 与 REVOLVE 在多个任务上的 OOD 精度甚至低于未优化的 CoT，印证了过度优化的分布过拟合问题，而 TextReg 能有效恢复并提升泛化性。
- **消融验证三组件协同必要**：去除任一部分均会导致性能下降，其中梯度纯化贡献最为突出。
- **鲁棒性极强**：即使将关键 LLM 组件降级为弱小模型，TextReg 的性能仅出现微小波动，在某些极端场景下甚至不降反升，说明正则化信号具有结构性，不严重依赖模型能力。

- **问题形式化新颖且深刻**：将提示过拟合归因为表征低效性，提出容量成本与范围狭窄性的可度量相互作用，为离散文本优化提供了理论视角。
