## 摘要
系统提示优化可在不修改底层模型的情况下改善智能体行为，生成人类可读且与模型无关的指令。现有方法构建一个提示智能体来优化任务智能体的系统提示，但该提示智能体自身的系统提示仍手工设计且固定不变。我们提出自进化提示优化（SePO），将提示智能体自身的系统提示与任务智能体的系统提示一同作为优化目标。SePO 采用自指设计，单一的提示智能体在开放式进化搜索中同时改进任务智能体的系统提示和自身提示，并维护候选提示的存档作为跳板。训练分为两个阶段：预训练在多任务池上进化提示智能体，随后微调将其应用到目标任务。在涵盖数学（AIME'25）、抽象推理（ARC-AGI-1）、研究生水平科学（GPQA）、代码生成（MBPP）和逻辑谜题（数独）的五个基准测试上，SePO 始终优于 Manual-CoT、TextGrad 和 MetaSPO，平均准确率比 Manual-CoT 提升 4.49 个百分点。预训练获得的提示优化技能还可泛化到预训练混合之外的任务，而非记忆每项任务的提示。

## Abstract
System prompt optimization improves agent behavior without modifying the underlying model, yielding human-readable, model-agnostic instructions. Existing methods build a prompt agent that refines task agents' system prompts, yet leave the prompt agent's own system prompt hand-engineered and fixed. We propose Self-Evolving Prompt Optimization (SePO), which treats the prompt agent's own system prompt as an optimization target alongside task agents' system prompts. SePO adopts a self-referential design. A single prompt agent improves both task agents' system prompts and its own under an open-ended evolutionary search that maintains an archive of candidate prompts as stepping stones. Training proceeds in two stages: pre-training evolves the prompt agent on a multi-task pool, and fine-tuning then applies it to a target task. Across five benchmarks spanning math (AIME'25), abstract reasoning (ARC-AGI-1), graduate-level science (GPQA), code generation (MBPP), and logic puzzles (Sudoku), SePO consistently outperforms Manual-CoT, TextGrad, and MetaSPO, improving the average accuracy by 4.49 points compared to Manual-CoT. The prompt optimization skill from pre-training also generalizes to tasks beyond the pre-training mixture, rather than memorizing per-task prompts.

### 1. 论文的核心问题与整体含义（研究动机和背景）
现有大语言模型（LLM）智能体的系统提示优化方法中，通常由专门的“提示智能体”依据评估反馈来优化任务智能体的提示。但这类提示智能体自身的系统提示仍是手工设计且固定不变的，这限制了优化能力随任务积累而增长的可能，使优化过程“受限在人类手工设计的水平”。  
SePO 的核心动机是打破这种不对等：**将提示智能体自身的系统提示也纳入优化目标，实现“自进化”**。这在更高层次上形成一种“自指”式的优化闭环，让提示优化本身成为一种可迭代改进的技能，而非一次性手工产物。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
SePO 的方法包含两个核心思想和一个两层训练流程：

- **自指（Self-Referential）优化**  
  将提示智能体视为一类特殊的“任务智能体”，其“任务”就是优化其他智能体的提示。因此，优化任务智能体提示的同一套流程同样被用来优化提示智能体自身的系统提示。  
  目标形式上可表达为：对任务智能体提示 \(p\) 优化，和对提示智能体自身的提示 \(\tilde{p}\) 优化，分别记为  
  \[
  p^\star = \arg\max_p \mathbb{E}_{(x,y)\sim D}[S(x,y,A(p,M,W)(x))]
  \]
  \[
  \tilde{p}^\star = \arg\max_{\tilde{p}} \mathbb{E}_{(\mathcal{T},A,E)\sim \tilde{D}}\left[\tilde{S}\left(\mathcal{T},A,E,\tilde{A}(\tilde{p},\tilde{M},\tilde{W})(\mathcal{T},A,E)\right)\right]
  \]
  两者在结构上一致，从而实现了自指闭合。

- **开放式进化搜索（Open-ended Evolutionary Search）**  
  采用基于档案的进化算法（见论文 Algorithm 1）：维持一个候选提示档案，每代采样父代，通过提示智能体产生子代（改进后的提示），以“是否优于父代”作为准入条件，从而利用历史提示作为进步的垫脚石。该搜索算法在两个训练阶段复用，仅优化目标不同。

- **两阶段训练流水线**  
  1. **预训练（Pre-training）**：在多任务池上进化提示智能体自身的系统提示 \(\tilde{p}\)，获得具备广泛提示优化能力的通用提示智能体。  
  2. **微调（Fine-tuning）**：固定预训练得到的 \(\tilde{p}^\star\)，用它来针对特定任务优化该任务智能体的系统提示 \(p\)。  
  这种拆分使预训练的一次性成本可在下游多个任务上平摊，同时让提示优化技能跨任务泛化。SePO 提供两个变体：SePO-Specialist（预训练与微调任务相同）和 SePO-Generalist（预训练使用多任务混合，为默认配置）。
