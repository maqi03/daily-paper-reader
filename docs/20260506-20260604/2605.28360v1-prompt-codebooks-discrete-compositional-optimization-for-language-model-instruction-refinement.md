## 摘要
自动提示优化（APO）为基于大语言模型的智能体工作流带来了显著增益。然而，现有方法将每个任务的提示视为单一的、实例盲的字符串，通过全局编辑进行优化，导致更新脆弱且无法复用学习到的子行为。我们提出提示码本（PCO），这是一种新颖的组合式提示优化框架，将APO重新定义为在有限自然语言本能—原子的、可复用的指令单元—词汇表上的离散学习。PCO将提示构建知识组织在一个离散码本中，并通过基于大语言模型的编码器将每个输入路由到一小部分条目；生成器将它们组合成针对冻结目标模型的提示；评判器发出结构化裁决，通过归因分解为每个变量的文本梯度，在语言值的最小-最大目标下共同训练编码器、生成器和码本。由此产生的路由是每实例化的：同一任务中的不同输入获得不同的本能组合，这种机制在实例盲方法下结构上无法表达。在Qwen3-8B和LLaMA-3.1-8B上的六个基准测试中，PCO相较于零样本最多提升+30.36分，在HotpotQA上比最强先前基线（GEPA）超出+3.34分，整体上超出+1.11分，并且仅使用K=16个本能，部署提示长度相较于MIPROv2减少最多14.1倍，相较于GEPA减少3.0倍。

## Abstract
Automatic prompt optimization (APO) has driven significant gains in LLM-based agentic workflows. However, existing methods treat each task's prompt as a monolithic, instance-blind string optimized through global edits, producing brittle updates and preventing the reuse of learned sub-behaviors. We propose Prompt Codebooks (PCO), a novel compositional prompt optimization framework that recasts APO as discrete learning over a finite vocabulary of natural-language instincts - atomic, reusable instruction units. PCO organizes prompt-construction knowledge in a discrete codebook and routes each input to a small subset of entries via an LLM-based encoder; a generator composes them into a prompt for the frozen target model; a critic emits a structured verdict that decomposes by attribution into per-variable textual gradients, jointly training the encoder, generator, and codebook under a language-valued min-max objective. The resulting routing is per-instance: different inputs in the same task receive different instinct compositions, a regime structurally inexpressible under instance-blind methods. Across six benchmarks on Qwen3-8B and LLaMA-3.1-8B, PCO improves over zero-shot by up to +30.36 points, surpasses the strongest prior baseline (GEPA) by +3.34 on HotpotQA and +1.11 in aggregate, and reduces deployed prompt length by up to 14.1x versus MIPROv2 and 3.0x versus GEPA using only K=16 instincts.

### 1. 论文的核心问题与整体含义
现有自动提示优化（APO）方法将每个任务的提示视为**单一的、实例盲的字符串**，对所有输入不加区分地使用同一个提示，并通过**全局编辑**进行优化。这种做法存在两大结构性问题：
- **实例盲性**：一条提示服务所有输入，无法针对不同难度的实例进行自适应调整。
- **全局纠缠**：每次更新重写整个提示，可能破坏其他已调优的行为，且学到的子行为无法在不同输入间复用。

针对这一缺陷，本文试图用**离散组合学习**的思路重新定义提示优化：将提示视为由一组可复用的“自然语言本能”（原子指令单元）组合而成，通过**每实例动态路由**实现自适应提示。这不仅能打破单一提示的局限，还能通过码本结构引入更强的正则化和行为级反馈。

### 2. 方法论：Prompt Codebooks (PCO)
PCO 框架包含四个协同工作的模块，所有变量均以自然语言形式存在，优化通过文本梯度驱动。

- **编码器（Encoder）** \(E_\theta\)：给定输入 \(x\)，从一个大小为 \(K\) 的离散码本中选择 \(S\) 个条目（\(S \ll K\)），实现**语义路由**而非最近邻量化，从而根据意图而非向量距离选择本能。
- **离散码本（Codebook）** \(C = \{c_1, \dots, c_K\}\)：每个 \(c_k\) 是一条简短的自然语言指令（如“回答前将问题分解为子问题”），作为可优化的文本变量。
- **生成器（Generator）** \(G_\phi\)：将选中的 \(S\) 条本能与输入 \(x\) 组合，生成一个流畅的系统提示 \(p\)。
- **评判器（Critic）** \(D_\psi\)：对比模型输出 \(y\) 和参考答案 \(y^\star\)，生成结构化的自然语言判决 \(\ell_{\text{text}}\)，指出失败模式和对应的提示元素。

**训练目标**为一个语言值的最小-最大问题：
\[
\Theta^\star = \arg\max_{\theta,\phi,C} \min_{\psi} \mathbb{E}\left[ r(M(p,x), y^\star) - \rho(D_\psi(y, x, p, y^\star)) \right]
\]
其中 \(r\) 为任务奖励，\(\rho\) 将文本反馈标量化后作为惩罚项。在实际训练中，\(\psi\) 固定为冻结的验证型 LLM，不参与内部优化，其作用是为归因提供结构化反馈。

**文本梯度分解**：评判器的反馈 \(\ell_{\text{text}}\) 通过一个基于 LLM 的归因算子 \(Attr\) 分解为三个部分：
- \(g_\phi\)（生成器忠实度）：本能是否被准确渲染到提示中。
- \(g_{c_k}\)（本能质量）：所选本能是否有效。
- \(g_\theta\)（路由质量）：编码器的选择是否合适。

这些“文本梯度”分别用于更新生成器、对应的码本条目的内容和编码器的路由策略。优化过程如算法1所示：每个训练步进行前向推理，生成反馈，归因到各组件，并用 LLM_upd 重写对应文本。

**探索机制**：为防止码本坍塌（部分本能不被使用），采用 \(\epsilon\)-greedy 路由和基于成功加权的采样。成功加权使用指数移动平均奖励 \(\bar{r}_k\) 和温度参数 \(\tau\)，鼓励访问历史表现好的本能。

**推理时**：仅保留训练好的 \(C\)、\(\theta\)、\(\phi\)。给定新输入 \(x\)，进行一次前向路由和生成，得到针对该实例的专属提示 \(p_x\)。同一任务的不同输入可使用不同的本能组合，实现实例级自适应。

### 6. 主要结论与发现
- **性能提升**：PCO 在零样本基础上最高提升 **+30.36 分**（LLaMA 3.1-8B），在 HotpotQA 上超越 GEPA **+3.34 分**，在多个基准的总体得分上以 **+1.11 分**领先最强基线。
- **提示压缩**：部署提示长度平均比 MIPROv2 短 **9.6 倍**，最多短 **14.1 倍**；比 GEPA 类方法短约 **2 倍**，且仅需 \(K=16\) 个本能。
- **结构化路由**：\(\epsilon\)-greedy 与成功加权探索有效防止码本坍塌，路由熵高达 3.78 比特，码本利用率 93.5%，没有死代码。
- **本能专业化**：编码器自发发现可复用的推理子程序，高频使用本能负责通用约束，稀有本能专攻高难度推理，成功率高但选择频率低。

### 7. 优点
- **概念新颖**：首次在提示优化中引入离散码本和组合生成，将原本连续、纠缠的优化问题转化为可路由、可重用的离散选择问题。
- **实例级自适应**：突破实例盲假设，实现同一任务内不同输入的不同提示，是现有 APO 方法结构上无法表达的能力。
- **局部化信用分配**：利用文本梯度将反馈精确传递给单个本能或生成器，避免全局更新的破坏性。
- **高效压缩**：在保证甚至提升性能的前提下大幅缩减提示长度，降低推理上下文开销。
- **实验扎实**：多任务、多模型、系统消融和丰富的定性分析，论据充分。

### 8. 不足与局限
- **格式化敏感任务可能受损**：激进压缩可能降低对格式、标点等硬约束的精准控制。
- **部分任务未占绝对优势**：在 LLaMA 3.1 上的 HoVer 中，PCO 未超过 GEPA+Merge，表明合并型进化方法在密集多跳验证任务中仍有独特优势。
- **训练计算成本较高**：文本梯度的多次 LLM 调用使其训练开销大于纯启发式搜索方法。
- **码本大小固定**：\(K\) 和 \(S\) 需预先设定，超参数对性能敏感，且大码本在有限训练数据下可能稀释优化信号。
- **未见跨任务迁移实验**：论文未验证一种任务的码本能直接迁移到其他任务，限制了“可复用性”的实证边界。
