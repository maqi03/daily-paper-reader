## 摘要
大型语言模型（LLMs）对用于指定任务目标和行为约束的提示高度敏感。许多近期的提示优化方法利用LLM生成的反馈迭代重写提示，但得到的提示往往变得更长，积累狭窄的样本特定规则，且在训练分布之外泛化能力差。我们将这种失败模式研究为提示分布性过拟合，并认为这反映了离散文本空间优化中缺乏表示控制。我们通过表征低效性来形式化这一观点，这是一种双因素度量，将提示低效性分解为容量成本和范围狭窄性，并将分布性提示过拟合归因于它们在优化过程中的耦合增长。我们提出TextReg，一个通过正则化文本梯度实现软惩罚目标的正则化框架，结合了双重证据梯度纯化、语义编辑正则化和正则化引导的提示更新。在多个推理基准测试中，TextReg显著改善了分布外（OOD）泛化，准确率相比TextGrad提升高达+11.8%，相比REVOLVE提升高达+16.5%。

## Abstract
Large language models (LLMs) are highly sensitive to the prompts used to specify task objectives and behavioral constraints. Many recent prompt optimization methods iteratively rewrite prompts using LLM-generated feedback, but the resulting prompts often become longer, accumulate narrow sample-specific rules, and generalize poorly beyond the training distribution. We study this failure mode as prompt distributional overfitting and argue that it reflects a lack of representation control in discrete text-space optimization. We formalize this view through representational inefficiency, a dual-factor measure that decomposes prompt inefficiency into capacity cost and scope narrowness, attributing distributional prompt overfitting to their coupled growth during optimization. We propose TextReg, a regularization framework that realizes a soft-penalty objective through regularized textual gradients, combining Dual-Evidence Gradient Purification, Semantic Edit Regularization, and Regularization-Guided Prompt Update. Across multiple reasoning benchmarks, TextReg substantially improves out-of-distribution (OOD) generalization, with accuracy gains of up to +11.8% over TextGrad and +16.5% over REVOLVE.

### 1. 论文的核心问题与整体含义
- **研究动机**：LLM对提示高度敏感，迭代优化（如TextGrad）虽能提升训练集表现，却经常导致提示**变长**、积累**样本特定规则**、**泛化能力差**。这种失败被称为**提示分布性过拟合**。
- **整体含义**：论文将该过拟合归因于离散文本优化中**表示控制缺失**，并将其形式化为**表征低效性（representational inefficiency）**——由**容量成本（C）** 与**范围狭窄性（W）** 的乘积衡量。当优化不加约束时，这两个因素耦合增长，导致提示变得冗长且适用范围窄，从而损害分布外（OOD）性能。作者提出**TextReg**，意在通过正则化手段解耦并抑制这一低效增长，增强提示的泛化能力。

### 2. 方法论
- **核心思想**：将正则化引入文本空间优化，在任务梯度（提升性能）之外加入**正则化梯度**（限制表示低效的增长），形成一个**软惩罚目标**：`min L_Dtrain(p) + λ I(p)`，其中 `I(p) = C(p)·W(p)`，`C(p)` 为 token 长度，`W(p) = 1 - 平均泛化范围`。
- **关键组件（三阶段）**：
  1. **双重证据梯度纯化（Stage 1）**：对待优化的原始文本梯度进行过滤，仅保留宽泛、可复用的规则。依据**局部批次证据**（是否与特定样本绑定）和**全局RuleBank频率证据**（历史中是否反复出现）将梯度分类为“广义规则”、“案例补丁”或“纯样式变化”，丢弃后两类，并将保留的梯度重写为简洁、通用的指令。
  2. **语义编辑正则化（Stage 2）**：通过比较上一轮与当前提示，**诊断容量（长度）和范围（规则范围）的变化**。若相对长度增长超过阈值（`τ_C = 0.2`）或语义分析发现范围窄化（`M_Δ`检测），则生成一个**正则化梯度**（表述为压缩、泛化或两者结合的建议）。
  3. **正则化引导的提示更新（Stage 3）**：在确保任务忠实性的候选提示集合中，选择**与正则化梯度最兼容**的编辑进行改写。当正则信号与任务信号冲突时，优先保证任务修正，避免过度约束。
- **公式表示**：整体文本梯度 `g_text = g̃_task + g_reg`，其中 `g̃_task` 是纯化后的任务梯度，`g_reg` 是由语义编辑正则化生成的对抗低效的方向。

- TextReg 在所有测试引擎和多数 OOD 任务上 **显著且一致地优于现有方法**，最高提升 **+11.8% (vs TextGrad)** 和 **+16.5% (vs REVOLVE)**。

### 7. 优点
- **问题形式化**：首次用 **容量成本 × 范围狭窄性** 的乘积度量提示低效，将过拟合归结为表示效率问题，理论见解清晰。
- **方法创新**：在离散文本优化中引入 **正则化梯度** 的概念，并设计了三个协调的环节，实现了任务性能与表示效率之间的软权衡。
- **多源证据过滤**：结合局部批次归因和全局 RuleBank 频率来筛选梯度，过滤掉无益的长度增长和窄规则，增强了泛化方向的选择。
- **实验严谨**：跨多种 LLM 架构、跨任务难度、统一预算的对比设计，加上消融与韧性测试，验证了方法的有效性和鲁棒性。
- **文本化诊断**：将容量和范围的诊断完全转化为自然语言指令，无需可微分操作，契合现有基于 LLM 的优化范式。

### 8. 不足与局限
- **任务范围有限**：当前仅针对 **单轮推理任务**（逻辑推理、算术），对于开放式生成、多轮对话、智能体指令等场景，提示结构模糊、容量成本跨轮共享，方法尚未验证。

- **RuleBank 累积偏差**：RuleBank 的记忆基于历史纯化梯度，若早期优化出现偏差，可能持续影响后续规则认可，但论文未深入讨论此潜在风险。
